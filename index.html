One contact API, two wallets

Make every introduction count.

Generate useful, on-brand contact passes from the same structured contact data, then fit pass creation into the systems you already use.

Apple Wallet passes

Return a ready-to-save .pkpass with contact details, configurable colors, optional profile thumbnail, and a scannable vCard QR code.

Google Wallet save links

Create a signed save URL for a Google Wallet Generic Pass, along with its object ID. Recipients can add the contact right to their wallet.

Contact data that travels

Every pass QR encodes a vCard 3.0 contact. Scan it to add the submitted details directly to a phone's address book.

Simple HTTP interface

Send JSON to a small REST API protected by an API key. Use the interactive docs and OpenAPI specification to integrate your stack.

Automation-ready

Use the included Workato connector to create an Apple pass or Google Wallet link as part of your business workflows.

Deploy on your terms

Run it with Docker Compose, a Docker container, or Kubernetes. Keep API access and signing credentials in your own environment.

A developer-friendly API

One request to make it real.

Post a contact once, and get back a downloadable Apple pass. Or request a Google Wallet save link from the same service.

POST/passesApple Wallet .pkpass
POST/passes/google-walletGoogle Wallet save link
GET/healthService health check
Request · Apple Wallet passcurl
# Save the response as a .pkpass file
curl -X POST http://localhost:8000/passes \
  -H "X-API-Key: $API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "givenName": "Ada",
    "surname": "Lovelace",
    "academicDegree": "PhD",
    "company": "Analytical Engines",
    "email": "ada@example.org",
    "phoneNumber": "+1 555 0100",
    "department": "Computing",
    "street": "1 Main St",
    "postalCode": "SW1A 1AA",
    "city": "London",
    "country": "UK"
  }' \
  -o contact.pkpass
